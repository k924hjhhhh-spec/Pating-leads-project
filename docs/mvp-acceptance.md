# MVP Acceptance Criteria

The first usable release must:

1. Accept a homeowner intake request.
2. Validate required fields and service-area boundaries.
3. Produce a structured ALEX 1 intake result.
4. Persist a lead ID and lifecycle state.
5. Run MAX 2 qualification without sending external messages.
6. Produce a preliminary RYAN 3 job card.
7. Show a human-review queue.
8. Allow an admin to approve, reject, or pause a lead.
9. Keep contractor/customer communications in test mode.
10. Expose health and basic audit status without private customer data.
11. Pass automated validation tests.
12. Deploy from GitHub to the configured Cloudflare service.
